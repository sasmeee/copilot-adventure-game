# Lantern of Moonfall

A command-line "choose your own adventure" game written in Rust, built with the help of GitHub Copilot.

## How to run

1. Install Rust: https://rustup.rs
2. Clone this repo
3. Run:
```
cargo run
```

## How to play

Type the number of your choice and press Enter. There are 4 different endings, and you can play again after each one.

## Built with

- Rust (standard library only)
- GitHub Copilot
- GitHub Codespaces
